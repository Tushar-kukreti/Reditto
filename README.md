# Reditto
A redis-inspired attempt to make a key-value pair using C++, for a linux environment. Used socket for communication and RESP as protocol.


# Commands

## System commands
### PING
### ECHO (Arg)
### FLUSHALL

## Key commands
### SET (key, value)
### GET (key)
### KEYS
### TYPE (key)
### DEL (key)
### EXPIRE (key, seconds)
### RENAME (old keyName, new keyName)
